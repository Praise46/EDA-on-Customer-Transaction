# EDA-on-Customer-Transaction
This is an exploratory data analysis on customer transactions to understand the patterns and outliers.

# Project Overview
This project performs an in-depth Exploratory Data Analysis (EDA) on a customer transaction dataset. The goal is to uncover purchasing patterns, analyse customer demographic behavior, detect outliers, and provide actionable insights for business optimisation, targeted marketing, and customer retention.

## Key Objectives
- Calculate total revenue and average transaction value.
- Identify the top 3 most popular product categories.
- Determine the most frequently used payment type.
- Compute monthly sales growth rate.
- Identify the top 5 highest spending customers.
- Determine the busiest sales day of the week
- Demographic Analysis: Explore the age distribution of customers based on birthdate.
- Analsze spending patterns across different age groups.

## Import Libraries

The libraries used in this project are 
- Pandas for data manipulation
- Numpy for numerical computing
- Matplotlib for data visualisation.
- Seaborn for statistical data visualisation.
- Scipy for a comprehensive set of numerical algorithms.
